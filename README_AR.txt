GLOBAL AI — نسخة المحادثة الحقيقية (واجهة + سيرفر)

شنو تبدّل؟
- عوضنا الرد التجريبي باتصال حقيقي مع Groq Chat API.
- النموذج الافتراضي: qwen/qwen3.8-27b (خاصك تتأكد أنه متاح فحسابك المجاني).
- أضفنا ذاكرة سياق للمحادثة الحالية (آخر 20 رسالة).
- مفتاح API كيبقى فالسيرفر داخل متغير بيئة، وما كيتحطش فـ app.js أو index.html.

مهم بزاف:
- ما تحطش المفتاح فـ Acode داخل ملفات الواجهة، وما تشاركه مع حتى واحد.
- هاد المشروع خاصو Node.js server باش يخدم /api/chat. فتح index.html بوحدو من Preview غادي يوري الواجهة فقط، وما غاديش يشغل السيرفر.
- Groq عندها Free plan بحدود استعمال. نموذج Qwen3.8 ظاهر كنموذج Preview وقد يتبدل أو يتوقف؛ راجع صفحة Models وLimits فحسابك.

تشغيل السيرفر:
1) خاص Node.js 20 أو أحدث على جهاز/استضافة كتدعم Node.
2) من مجلد المشروع شغّل: npm install
3) نسخ .env.example إلى .env.
4) حط مفتاحك فـ GROQ_API_KEY داخل .env على السيرفر فقط.
5) شغّل: npm start
6) افتح عنوان السيرفر فالمتصفح. نفس السيرفر كيقدم الواجهة و /api/chat.

API:
POST /api/chat
Body: { "messages": [{"role":"user","content":"Salam"}] }

فحص السيرفر:
GET /api/health
